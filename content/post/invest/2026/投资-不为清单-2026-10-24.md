查理·芒格常说：“如果我知道自己会在哪里死去，我就永远不去那个地方。”段永平也反复强调，投资最重要的是建立自己的 **Stop Doing List（不为清单）**——少犯致命错误，复利自然会发生。

| 序号 | 不为清单 | 核心说明（一句话准则） | 详情 |
| :--- | :--- | :--- | :--- |
| **01** | **不熟不做（能力圈外不做）** | 无法讲清公司怎么赚钱、客户为什么复购、未来 5–10 年现金流如何的，坚决不买正式仓位。 | |
| **02** | **不加杠杆** | 绝不借钱、融资或使用高倍合约炒股，不用短期要用的生活资金投资，永远保留充足净现金。 | |
| **03** | **不买商业模式差、企业文化不正** | 投资必先看商业模式与企业文化；不买无真实自由现金流、无护城河，或管理层不诚信、算计股东的公司。 | |
| **04** | **不买下行周期和夕阳行业** | 行业处于下行周期（秋冬季）或面临结构性衰退时绝对不买，不逆时代重力，不高估自己的判断力。 | |
| **05** | **不做逆境反转（困境反转）** | 不赌基本面已经恶化、陷入泥潭的公司能“起死回生”，绝不因为股价相比历史高点跌了 80%–90% 就去抄底。 | |
| **06** | **不根据个人爱好、信仰或名人背书** | 不因为自己是产品爱好者、认同某种宏大情怀，或看到知名大佬持仓就盲目跳过基本面验证去买公司。 | |
| **07** | **不做短线波段（不做 T）** | 不为了赚差价或害怕短期回调而频繁高抛低吸，避免把优质筹码做丢或陷入踏空焦虑。 | |
| **08** | **不预测市场** | 不猜测宏观大盘涨跌、牛熊拐点或短期股价底部，不根据市场情绪噪音临时起意买卖。 | |
| **09** | **不因“损失厌恶”而死扛错误仓位** | 发现买错、逻辑证伪或仓位超负荷影响睡眠时，立即纠正，绝不因为“等回本再卖”的执念而拖延。 | |
